Tolerance Issue vs. Algorithmic Bug: Summary Matrix

1. pymatgen on H3_D3h.xyz Tolerance + Factor-of-2 Bug

PointGroupAnalyzer defaults to tolerance=0.3 Å. In cluster_sites(mol, tol) (analyzer.py:1645), radial distances are stored as 2D points [[r, 0]] and averaged with np.mean(val) across both columns, halving every atom's distance to r / 2 = 0.25 Å! Because 0.25 < 0.30, all 3 H atoms are absorbed into origin_site, leaving clustered_sites empty and crashing min(valid_sets, key=len). Setting tolerance ≤ 0.24 fixes it.

2. pyscf on C4N4Pt_C4h.xyz Algorithmic Bug

Fails at all tolerances (1e-7 to 0.1). In pyscf/symm/geom.py:244, detect_symm requires the rank-2 Cartesian multipole tensor to have a degenerate strictly positive eigenvalue (w2_degeneracy[w2_degen_values > 0] ≥ 2) before searching for $C_n$ ($n \ge 3$). In a planar $C_{4h}$ pinwheel ($z=0$), $(x^2-y^2)$ and $xy$ transform as the 1D $B_g$ irrep and split (`0.648`, `6.633`), while $(xz, yz)$ are `0`. Thus pyscf tags the molecule as a $D_{2h}$ subgroup and returns C2h.

3. pyscf on C5H5P_C5.xyz Tolerance Threshold

In search_possible_rotations (geom.py:710), candidate rotation orders $n$ are filtered by nfrac = 2*pi / (pi - ang); abs(nfrac - n) < TOLERANCE where TOLERANCE = 1e-5. Floating-point rounding in $\arccos$ on the 12-decimal-place coordinates causes abs(nfrac - 5) to slightly exceed 1e-5. Increasing pyscf.symm.geom.TOLERANCE = 1e-4 restores C5.

4. pointgroup on C2H2O2_D2h.xyz Algorithmic Bug

C2H2O2_D2h.xyz is an accidental spherical top ($I_x = I_y = I_z = 2/3$). pointgroup checks eig_degeneracy == 3 and calls _spherical() with no fallback to $D_{2h}$. Inside _spherical(), while main_axis is None: multiplies self._tolerance_ang *= 1.01 217 times until the angular tolerance balloons past $35^\circ$, hallucinating a false $C_3$ axis and returning Th.

5. molsym on C5H12_T.xyz & B12H60_I Unimplemented Path + O(N⁵) Loop

In molsym/pgdetect/flowchart.py:67, the spherical-top tetrahedral branch literally has # Tetrahedral, TODO: No path for T and returns "Th" if invertable else "Td". Additionally, find_C3s_for_Ih (flowchart_helper.py:426) uses $O(N^3)$ nested atom loops calling $O(N^2)$ isequivalent, taking 82.8 s on B12H60_I.xyz.

6. pgmol-inkling on Rotated XYZs Frame Dependence

Scores 91/91 on canonical coordinate-aligned fixtures, but drops to 42/91 (46.2%) under random 3D rotations because symmetry_finder.py seeds axes from hardcoded [1,0,0], [0,1,phi] vectors, caps atom-pair sampling at 30 pairs, and tests $S_n$ only along [0,0,1], [0,1,0], [1,0,0], and [1,1,1].

Architectural Comparison: ASA PGMol vs. test-pgmol (my-try)

Dimension Autonomous-Scientific-Agents/PGMol (OpenCode · GPT-5.6 Sol) test-pgmol (my-try) (OpenCode · Gemini 4 Argon)
Core Formulation Exhaustive $O(3)$ group discovery via orthonormal frames: picks a non-collinear atom pair $(a_0, b_0)$ as source frame $F_{\text{src}}$, loops over all same-element pairs $(a_i, b_j)$ at matching radii to form $F_{\text{tgt}}$, and tests $O = F_{\text{tgt}}\operatorname{diag}(1,1,\pm 1)F_{\text{src}}^T$. Shell-partitioned geometric axis generation & Schoenflies tree: partitions atoms into radial shells per element, generates candidate axes from shell covariance eigenvectors, pair midpoints/differences/cross-products, and nearest-neighbor pairs/triplets.
Classification Rule Counts total proper/improper matrices in the discovered group (≥60 → $I/I_h$, ≥24 → $O/O_h$, ≥12 → $T/T_h/T_d$); extracts rotation orders via $\arccos((\operatorname{tr}(O)-1)/2)$. Filters candidate orders $n$ by shell-size divisibility ($s \equiv 0, 1, 2 \pmod n$), counts distinct $C_5/C_4/C_3$ axes for $I/O/T$, and directly probes perpendicular $C_2$, $\sigma_h$, $\sigma_v/\sigma_d$, and $S_{2n}$.
Atom Permutations & Matching Vectorized nearest-neighbor argmin when unique; falls back to an exact DFS bipartite perfect matching (_perfect_matching) when tolerance spheres overlap. Shell-by-shell bidirectional squared-distance check with a 1-atom fast-rejection probe (grp[0] @ op_matrix.T) before computing the full distance matrix on shells with $>8$ atoms.
Runtime Scaling 0.129 s Core / 2.656 s Challenge. On single-shell 60-atom cages ($\text{C}_{60}$, $\text{B}_{12}\text{H}_{60}$), radial pruning cannot shrink the 60-atom shell, testing $60 \times 59 \times 2 = 7{,}080$ candidate frames. 0.094 s Core / 0.733 s Challenge (~3.6× faster). Restricts candidate pairs/triplets on shells $>24$ atoms to nearest neighbors and rejects invalid rotations in $O(1)$ via the single-atom probe.
